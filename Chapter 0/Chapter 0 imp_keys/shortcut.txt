Strings are immutable.
Lists are mutable.
Tuples are immutable.
Dictionaries are mutable.
Sets are mutable but elements in there are immutable.


Escape Sequence -->>> \n -> New line, \t -> Tab, \´ -> Singlequote, \\ -> Backslash





Strings

1. upper(): Converts the string to uppercase.
2. lower(): Converts the string to lowercase.
3. strip(): Removes leading and trailing whitespace.
4. split(): Splits the string into a list of substrings.
5. join(): Joins a list of strings into a single string.
6. find(): Finds the index of a substring.
7. replace(): Replaces a substring with another string.
8. startswith(): Checks if the string starts with a substring.
9. endswith(): Checks if the string ends with a substring.

Example:

s = "Hello World"
print(s.upper())  # Output: "HELLO WORLD"
print(s.split())  # Output: ["Hello", "World"]


Lists

1. append(): Adds an element to the end of the list.
2. extend(): Adds multiple elements to the end of the list.
3. insert(): Inserts an element at a specific index.
4. remove(): Removes the first occurrence of an element.
5. pop(): Removes and returns an element at a specific index.
6. index(): Finds the index of an element.
7. count(): Counts the number of occurrences of an element.
8. sort(): Sorts the list in-place.
9. reverse(): Reverses the list in-place.

Example:

my_list = [1, 2, 3]
my_list.append(4)
print(my_list)  # Output: [1, 2, 3, 4]
my_list.sort()
print(my_list)  # Output: [1, 2, 3, 4]


Tuples

Tuples are immutable, so they have fewer methods:

1. index(): Finds the index of an element.
2. count(): Counts the number of occurrences of an element.

Example:

my_tuple = (1, 2, 3)
print(my_tuple.index(2))  # Output: 1


Dictionaries

1. keys(): Returns a view object that displays a list of all keys.
2. values(): Returns a view object that displays a list of all values.
3. items(): Returns a view object that displays a list of all key-value pairs.
4. get(): Returns the value for a given key if it exists.
5. update(): Updates the dictionary with new key-value pairs.
6. pop(): Removes and returns the value for a given key.
7. clear(): Removes all items from the dictionary.

Example:

my_dict = {"name": "John", "age": 30}
print(my_dict.keys())  # Output: dict_keys(["name", "age"])
print(my_dict.get("name"))  # Output: "John"
my_dict.update({"city": "New York"})
print(my_dict)  # Output: {"name": "John", "age": 30, "city": "New York"}


Sets

1. add(): Adds an element to the set.
2. remove(): Removes an element from the set.
3. union(): Returns a new set with elements from both sets.
4. intersection(): Returns a new set with elements common to both sets.
5. difference(): Returns a new set with elements in one set but not the other.
6. clear(): Removes all elements from the set.

Example:

my_set = {1, 2, 3}
my_set.add(4)
print(my_set)  # Output: {1, 2, 3, 4}
my_set.remove(2)
print(my_set)  # Output: {1, 3, 4}
